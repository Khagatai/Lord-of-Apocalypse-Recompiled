# Native Windows launcher

**Settings** is available in the launcher and through F1. Both use the same
preferences: graphics, display, advanced effects, language, frame rate and presets.
The launcher offers a controls reference as well. Save settings before returning
to Play; Cancel discards the draft. Preferences edited elsewhere must be reloaded
before saving. Launcher settings are unavailable while its game is running; use
F1 for live changes. Networking and tester support remain in-game only.

English WIP and Japanese are the two playable languages. The retired standalone
v1.6 ISO is not required at startup or generated by player setup. The small
original patch is retained privately only for temporary translation build inputs.

The source launcher uses a dark slate palette, warm gold accents and an
original geometric emblem, with a primary Play action and a Basic graphics
toggle. Launch details are collapsed normally and expand automatically after
a failed child process. Open log exposes the existing local launcher log.
The native controls remain keyboard-accessible. Fonts and layout scale with
Windows DPI changes, with the initial size limited to the desktop work area.
The executable icon uses the locally supplied logo, converted to a transparent,
seven-size Windows ICO under `private/branding/`. This artwork stays out of the
source export. A source build without that optional ICO uses the geometric
fallback. There is no web runtime or image download.

Open **LordOfApocalypse.exe**, then click **Play**. In the complete tester ZIP,
the first run asks for the user's unmodified Japanese ISO and reconstructs the WIP
English image locally with SHA256 checks. The bundled interpreter and native
dependencies avoid Python, Git, compiler and emulator installation for players.
Keep the entire extracted folder together; the EXE is a front end, not a single
file containing the game. No ISO, saves or personal preferences ship in the ZIP.
Install in an ASCII-only path such as `C:\Games\LordOfApocalypse-Recomp`.
Spaces are supported. The current native runtime cannot open game data from
non-ASCII installation paths; launch reports this before starting the runtime.
The launcher UI and ISO setup support Unicode filenames, but that does not
establish Unicode-path support in the separately compiled native runtime.

The basic-graphics checkbox applies a per-run troubleshooting preset. It uses
the normal saves. F1 settings changes still persist when explicitly selected.
Details and **Open launcher log** show setup errors; the single latest log is at
`private/launcher/latest.log`. The launcher minimizes when the game starts and
exits after the game closes. Closing it during setup/play minimizes it so an
in-progress save or setup is not interrupted. Close the game normally.

The launcher uses `CreateProcessW` and explicit Windows argument quoting. It
does not execute a shell. Its supervised Python helpers use a hidden console;
game windows and the ISO picker remain visible. A source checkout uses the
existing verified preview path; a packaged build uses `tools/tester-start.py`.

Rebuild with a local Windows x64 GCC compiler:

```powershell
private/tools/python314/python.exe tools/build-windows-launcher.py
```

Advanced direct launch/preflight remains available:

```powershell
private/tools/python314/python.exe tools/launch-preview.py --variant saved
private/tools/python314/python.exe tools/launch-preview.py --variant saved --check-cached
```

Cloning the source repository alone does not supply the prepared runtime,
private translation data or game assets. Follow REPRODUCTION.md for development.
The optional multiplayer provider remains a Steam App ID 480 development test.
Public binary distribution requires a separate content/licence review. The
beta's unresolved audio and campaign/multiplayer acceptance gates remain open.
